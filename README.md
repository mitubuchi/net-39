# net-39

招待された人どうしで、感謝の気持ちを**トークン**として送り合える場所です。
これからメッセージのやり取りもできるようにしていきます。

## ログイン

### 👉 [https://net-39.com/login](https://net-39.com/login)

登録した端末の **指紋・顔認証・PIN** で入ります。パスワードはありません。

> いまは外のネットワークからの公開を準備しています。開けないときは、しばらくお待ちください。

---

## はじめての方へ

net-39 は**招待制**です。会員から届く招待で登録します。

1. 届いた**招待メール**のリンクを開く
2. 招待してくれた人から、メールとは別に伝えられる **招待コード**（6〜8 桁の数字）を入れる
3. 端末の案内に沿って、指紋・顔認証・PIN で確かめる（**パスキー**を作ります）
4. 相手に表示される **ニックネーム** を決める

招待のリンクは、届いたご本人が 1 回だけ使えます。ほかの人に転送しないでください。

## できること

| | |
|---|---|
| **トークンを送る** | 毎週 10 ずつ送れる数が増えます（最大 120）。ひとことを添えられます |
| **トークンを受け取る** | 届いたものを、受け取るかお断りするか選べます。受け取ったトークンは、ほかの人には渡せません |
| **メッセージ** | 準備中です |

相手には、あなたの**ニックネーム**と、同じ名前の人と見分けるための**印**（`7F3A·C21E` のような 8 文字）が表示されます。
メールアドレスは、ほかの会員には見せません。

## 大切にしていること

- **パスワードを使いません。** パスキーは端末の中にあり、外に出ません
- **鍵は、あなたの端末の中でしか開きません。** サーバーに届くのは、暗号化したものだけです
- **端末をなくしても、取り戻せます。** 保護者 2 人の承認と 48 時間の猶予のあとで鍵を差し替えます。猶予のあいだは、ご本人が止められます
- **大手のクラウドに頼りません。** 小さな拠点をいくつか置いて、みんなで支える形で運営しています
- **ほかの人と共用している端末では登録しないでください。** パスキーはその端末に保存されます
